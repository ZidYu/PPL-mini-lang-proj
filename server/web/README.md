# Mini Programming Language and Interpreter UI

## Files
- `index.html`: pages, header, navigation, editor, output, guide, documentation, and about content.
- `styles.css`: responsive modern UI with Light, Dark, and System themes.
- `app.js`: navigation, examples, guide tabs, theme persistence, and a browser demonstration interpreter.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important project note
The browser interpreter supports variables, reassignment, numbers, strings, booleans, arithmetic, comparisons, logical operators, print, if/else, while, functions, returns, lexical environments, and first-class function values. For your final submission, compare this browser implementation with your Python implementation and connect the UI to your Python backend if Python is the required source of truth.
