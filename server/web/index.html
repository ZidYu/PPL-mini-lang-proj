PROJECT DOCUMENTATION
Mini Programming Language and Interpreter
Course: CSS125P - AM5
Members: Sanchez, Jasmin Ariane C.; Sosa, Leon Gabriel; Yu, Zidane Elric; Espina, Felicity Ann.
Architecture
Scanner → Recursive Descent Parser → AST → Evaluator.
Errors
Illegal character, invalid syntax, undefined variable, type mismatch, and division by zero errors are reported.
Host language
Python is the planned host language because it supports fast iteration, readable code, and dataclass-based AST nodes.
Scope
This is an educational interpreter, not a production compiler or machine-code generator.
Grammar sketch
program     → statement* EOF
statement   → declaration | assignment | print | if | while | function | return
expression  → equality
assignment  → IDENTIFIER "=" expression
function    → "function" IDENTIFIER "(" parameters? ")" ":" statement* "end"

  
ABOUT
Why this project?
This project was created to make programming language concepts tangible. Instead of only reading about parsing, scope, and execution, learners can write small programs, see how they are tokenized, and observe how the interpreter evaluates each statement.
Mini Language demonstrates the core ideas behind compiler and interpreter design in a small, approachable form: grammar rules, lexical analysis, AST construction, variable environments, control flow, and function behavior.
Learning goals
Students explore how a language is structured and how runtime behavior differs from syntax. The project helps connect theory to execution.
Core concepts
It covers expressions, assignment, branching, loops, functions, closures, and dynamic runtime checks for invalid operations.
Project purpose
The interpreter is designed as an educational tool for understanding how a simple language can be built from the ground up.
Real-world value
Even though this is a lightweight interpreter, it mirrors the same stages used in larger language tools: scanning, parsing, interpreting, and checking semantics.
Implementation note
The browser version is a demonstration frontend for experimenting with the language. The underlying Python interpreter remains the main implementation and can be extended or connected to a backend for a more complete project submission.
Team note
This project is part of CSS125P - AM5, with the goal of building a working mini-language interpreter and showcasing the formal principles behind it.
